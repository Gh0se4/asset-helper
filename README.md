# Asset Helper

**FOFA / Hunter 网络资产采集与表格化展示工具**

在测绘平台上翻页浏览时，把资产数据实时汇聚成一张可操作的表格。

## 它解决什么问题

用 FOFA / Hunter 做资产梳理时，你一定经历过：

- 😩 结果散落在页面卡片里，想取某一列数据只能逐条手抄
- 😩 翻到第二页，第一页的数据就"忘了"
- 😩 想把几十条 IP、URL、域名批量带走，只能靠零散复制

**Asset Helper 不打断你的浏览习惯**：你照常搜索、翻页，它在页面内浮出一个面板，把当前页资产实时汇聚成一张可操作的表格 —— 取列、暂存、去重、导出，一步到位。

<br>

## ✨ 核心特性

### 📥 自动采集

- **打开即采**：进入支持的平台结果页，数据自动汇聚，无需任何手动触发
- **被动提取**：只读取页面已渲染的内容，不发起额外请求、不调用平台 API、不修改页面行为
- **平台白名单**：仅在 FOFA / Hunter 上工作，其他站点零开销（不注入、不轮询、不响应）

### 🖥 页面内悬浮面板

- 页面内浮层，不跳转、不遮挡，可拖动、可缩放、可关闭
- **位置尺寸记忆**：刷新页面后自动回到原处
- 标题栏呼吸灯：一眼确认采集器正在工作

### 📊 结构化表格

- 16 个字段一目了然：`IP`、`端口`、`IP:端口`、`URL`、`域名`、`标题`、`协议`、`组件`、`证书 CN`、`指纹` 等
- Tabulator 虚拟滚动 + 紧凑行高，上千行依然流畅

### ⚡ 列级操作 · 列头徽章

- 每个列头自带两个快捷徽章：**追加** / **覆盖**
- 一键把整列数据写入暂存区，无需右键、无需逐条复制

### 📋 内置暂存区

- 单列文本区域，一行一条数据，随取随用
- 支持 **追加 · 覆盖 · 去重 · 复制 · 导出 · 清空**
- 内容自动持久化 —— 关面板、刷新页面都不丢

### 🔄 替换 / 累积双模式

- **替换模式**（默认）：表格始终展示当前页面的数据，刷新即刷新
- **累积模式**：手动翻页时数据持续累积，跨页自动整行去重，不漏不重
- 模式随时切换，已采集的数据不会被清空

### 📤 一键导出

- **CSV**：带 UTF-8 BOM，Excel 直接打开不乱码
- **JSON**：保留完整字段结构，方便二次处理

### 🔒 数据不出浏览器

- 数据只保存在浏览器本地存储，**不经过任何第三方服务器**
- 扩展不发起任何外部网络请求，无遥测、无统计
- 会话数据随浏览器关闭自动清空

## 🚀 安装

### 从源码构建

```bash
# 1. 克隆仓库
git clone https://github.com/Gh0se4/asset-helper.git
cd asset-helper

# 2. 安装依赖并构建
npm install
npm run build

# 3. 加载扩展
#    打开 Chrome → chrome://extensions/
#    开启右上角「开发者模式」
#    点击「加载已解压的扩展程序」→ 选择项目下的 dist 目录
```

> 需要 Node.js 18+ 与 Chrome 102+。

### 更新

重新构建后在 `chrome://extensions/` 点击扩展的刷新按钮即可。已打开的测绘平台页面刷新一次生效。

## 📖 使用指南

**1. 打开一个支持的平台页面**

在 FOFA 或 Hunter 上执行一次搜索，进入结果列表页并保持登录状态。

**2. 唤出悬浮面板**

点击浏览器工具栏中的 Asset Helper 图标，页面内浮出采集面板。

**3. 查看汇聚的资产表格**

当前页的资产会自动解析成表格，顶部统计胶囊实时显示：
**行数 / 页数 / 唯一 IP 数**。

**4. 取列 · 写入暂存区**

找到想要的列（比如 `IP:端口`），点击列头的 **追加** 或 **覆盖** 徽章 —— 整列数据立即写入下方暂存区。

**5. 翻页继续采集**

- 默认 **替换模式**：翻到哪页，表格就是哪页的数据
- 打开 **累积模式**：翻页持续累积，自动去重，适合把多页结果汇总成一份清单

**6. 整理与导出**

暂存区支持一键去重、复制、导出；表格区可直接导出 CSV / JSON。

<br>

## 🔧 技术实现

- **Manifest V3**：Service Worker 后台 + 按站点匹配的 Content Script
- **被动提取**：基于页面 DOM 结构解析，不拦截请求、不改动页面
- **性能设计**：`MutationObserver` 防抖（600ms）+ 10s 兜底轮询；页面不可见时自动暂停，切走零开销
- **状态管理**：会话数据存于 `chrome.storage.session`（浏览器关闭即清），面板位置与暂存区存于 `chrome.storage.local`
- **表格**：Tabulator 6.x 虚拟滚动
- **构建**：Vite + CRXJS

## ❓ 常见问题

**Q：点击图标没有反应？**
A：扩展只在支持的平台页面上响应。请确认当前标签页是 FOFA 搜索结果页或 Hunter 资产列表页。

**Q：面板打开但表格是空的？**
A：等待 1–2 秒让提取器完成解析；若仍为空，刷新一次页面（扩展更新后需要刷新页面重新注入）。

**Q：累积模式下翻页后行数没有翻倍？**
A：这是正常的。累积模式会对完全相同的行自动去重，只有新出现的资产才会追加。

**Q：角标数字怎么消失了？**
A：角标只在当前标签页处于支持的平台时显示；切到其他网站会自动隐藏，但数据不会丢失，切回来即恢复。

**Q：数据会一直保存吗？**
A：会话数据保存在浏览器会话存储中，关闭浏览器后清空。需要长期保留请及时导出，或先写入暂存区（暂存区为持久存储）。
